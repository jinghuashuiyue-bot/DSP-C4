七种典型序列的 DTFT 与 DFT

DTFT: X(ejω) = Σn x(n)·e-jωn   |   DFT: X(k) = Σn=0N-1 x(n)·e-j2πkn/N
时频双域延拓观察：时域与频域图表已同步扩展。在时域中，实心点代表 DTFT 对应的非周期原序列（补零延拓）；空心红圈代表 DFT 隐含的时域周期延拓 $\tilde{x}(n)$。与之对应，在频域中 DFT（红点）也表现为 DTFT（蓝线）的周期延拓采样。

圆周移位 Circular Shift

y(n) = x((n - m))N · RN(n)，即将 x(n) 以 N 为周期延拓后再取主值

圆周卷积 Circular Convolution

y(n) = x(n) Ⓝ h(n) = Σm=0N-1 x(m)·h((n-m))N·RN(n)
3D 图展示了 h((n-m))N 随 n 的滑动过程：每行对应一个 n 的取值， 将该行与 x(m) 逐点相乘求和即得圆周卷积 y(n)。

频域采样定理验证

对长度为 M 的 x(n)，其 DTFT 为 X(ejω)，在 [0,2π) 取 N 点采样 X(k) = X(ej2πk/N)。
IDFT[X(k)] = xN(n) = Σr x(n+rN) · RN(n)，即 x(n) 以 N 为周期延拓后的主值。
无混叠条件：N ≥ M
观察：当 N < M 时，时域出现周期延拓混叠，重构的 DTFT 与原 DTFT 不一致； 当 N ≥ M 时，xN(n) 的主值即原 x(n)，由 X(k) 可通过内插公式精确恢复 X(ejω)。
内插公式： X(ejω) = Σk=0N-1 X(k)·Φ(ω - 2πk/N)， Φ(ω) = (1/N)·sin(ωN/2)/sin(ω/2)·e-jω(N-1)/2
